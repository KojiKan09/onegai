# 費用メモ

同居する大学生と母親のあいだで、生活費や必要経費のやりとりを一か所にまとめるアプリの画面モック。

- モック: https://kojikan09.github.io/onegai/ (`index.html` をブラウザで開くだけでも動く)
- 設計メモ・監修結論: [DESIGN.md](DESIGN.md)

## 目的

本来なら母親が出してくれるはずの出費を、大学生が言い出せずに自分の財布から払ってしまい、
手元のお金が不必要に減っている。**頼み損ねをなくすこと**がこのアプリの目的。

そのための中心機能が**メモとまとめ送信**。買った瞬間はメモとして残すだけで相手に通知は飛ばず、
あとから複数をまとめて一度に送れる。記録する瞬間と、頼む瞬間を切り離している。

## モックの使い方

右上の切り替えで、受け取る側と渡す側の視点を行き来できる(モック専用。本番では役割は固定)。
データは端末のブラウザ内にだけ保存され、設定の「デモデータを初期化」で戻る。
