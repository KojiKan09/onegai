# 費用メモ

同居する大学生と母親のあいだで、生活費や必要経費のやりとりを一か所にまとめるアプリ。

## 目的

本来なら母親が出してくれるはずの出費を、大学生が言い出せずに自分の財布から払ってしまい、
手元のお金が不必要に減っている。**頼み損ねをなくすこと**がこのアプリの目的。

中心にあるのは**メモとまとめ送信**。買った瞬間はメモとして残すだけで相手に通知は飛ばず、
あとから複数をまとめて一度に送れる。記録する瞬間と、頼む瞬間を切り離している。

設計の根拠と文言の決まりは [DESIGN.md](DESIGN.md) にある。文言を変える前に必ず読むこと。

## 構成

```
docs/          ブラウザで動く部分(Workers が配信し、GitHub Pages でも開ける)
  logic.js     状態モデルと更新規則。ブラウザと Worker が共有する唯一の実装
  app.js       画面
  index.html   雛形と CSS
  sw.js        通知を受け取る Service Worker
worker/
  src/index.js API と定時処理
  src/push.js  Web Push(VAPID + RFC 8291)を WebCrypto だけで実装
  schema.sql   D1 のテーブル
wrangler.toml  Cloudflare の設定
```

規則を `logic.js` の一か所に置いているので、画面とサーバーで判定がずれない。
サーバーが無い場所(GitHub Pages など)では同じ規則のままお試しモードで動く。

## 動かす

```sh
npm install
npm run db:init          # ローカルの D1 にテーブルを作る
npm run vapid            # 通知の鍵を作る(下の手順を見る)
npm run dev              # http://127.0.0.1:8788
```

`npm run vapid` が出す公開鍵は `wrangler.toml` の `VAPID_PUBLIC_KEY` に貼る。
秘密鍵はローカルでは `.dev.vars` に置き(git 管理外)、本番では `wrangler secret` で登録する。

```
# .dev.vars
VAPID_PRIVATE_KEY = "..."
ALLOW_TEST_CRON = "1"
```

## 試す

```sh
npm run test:push        # 通知の暗号を、実際に復号して確かめる
npm run test:api         # API の権限と流れ(要 npm run dev)
npm run test:live        # 2つのブラウザで紐づけて通し確認(要 npm run dev)
```

`test:live` は Edge をヘッドレスで2つ立ち上げ、受け取る側と渡す側の端末として操作する。

## 公開する

初回の手順は [DEPLOY.md](DEPLOY.md) に一段ずつ書いてある。
以後は `npm run deploy` だけでよい。定時処理(毎日 00:00 UTC = 日本時間の朝9時)も一緒に登録される。

## 使いはじめ

1. 受け取る側が「はじめる」を押し、ふたりの呼び名を入れて6文字のコードを出す。
2. 渡す側の端末で同じURLを開き、「コードでつながる」からそのコードを入れる。
3. **その場で、渡す側の端末の通知まで設定してしまう。**
   iPhone と iPad はホーム画面に追加しないと通知が一切届かない。
   受け取る側が代わりに操作してあげるのが確実。
4. テスト通知が鳴るのを本人に見てもらう。鳴るまでは通知は届いていない。

端末を買い替えたときは、受け取る側が設定から新しいコードを出してつなぎ直す。

## 決めごと

- 送信前の画面に合計金額を出さない。外す判断を誘発し、目的と逆行するため。
- 渡す側には「メモ」「自分で払った」「やめた」を一切見せない。サーバーが送る前に落としている。
- 渡す側にメモの催促を送らない。受け取る側にだけ、週に一度だけ件数を知らせる。
- 通知の文面と画面に「お願い」「支給」「依頼」「請求」「申請」「却下」は使わない。
